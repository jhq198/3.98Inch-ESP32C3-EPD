使用说明与安全

当前固件的 BLE 链路不加密。Wi-Fi 密码会经蓝牙明文发送；只在可信的近距离环境配网。 页面不会保存或记录密码。
  • 需要支持 Web Bluetooth 的 Chrome 或 Edge，并通过 HTTPS 打开；iOS Safari 不支持。
  • 设备需已上电且在蓝牙范围内。弹窗会列出浏览器发现的 BLE 设备（不含经典蓝牙设备），请选择“EPD-Calendar”；无需先在手机系统设置中配对。
  • 命令“已保存”仅表示设备接受了凭据；页面会继续查询设备的 Wi-Fi 连接状态。
